# Portfolio Overview

I build practical automation for infrastructure and cloud environments, with a focus on making repetitive administration safer, more observable and easier to operate.

## Areas of work represented here

- PowerShell automation for Windows and Microsoft 365 administration
- Microsoft Graph and Entra ID reporting
- Exchange Online auditing
- Active Directory administration
- Linux operational scripting
- REST API integrations and authentication boundaries
- Asynchronous processing with RabbitMQ-compatible messaging
- Azure resource administration and reporting
- CI/static analysis and configuration hygiene

## How the projects fit together

```text
Identity / M365 ───────┐
Directory / Windows ───┤
Linux / Azure ──────────┼──> Automation
APIs / messaging ──────┤
Monitoring ─────────────┘
             |
             v
     structured output + repeatable operations
```

The code is intentionally split into small tools so an administrator can understand, test and adapt one task without taking on a large framework.
