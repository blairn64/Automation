# Portfolio Positioning

This repository is the practical infrastructure side of my portfolio. It focuses on turning repetitive administration and troubleshooting into small, understandable tools that collect useful data, automate repeatable work and produce structured results.

## Strongest evidence

### Identity and Microsoft 365
- Microsoft Graph integration
- Entra sign-in reporting patterns
- Exchange privilege auditing
- Active Directory administration
- Runtime authentication and secret separation

### Infrastructure and cloud
- PowerShell administration
- Linux/Bash operational tooling
- Azure resource administration and reporting
- Docker-based lab environments
- CI and static analysis

### Integration and data flow
- REST APIs
- RabbitMQ-compatible messaging
- JSON event contracts
- Synthetic manufacturing telemetry
- Monitoring-oriented structured output

## Interview discussion points

1. Turning repetitive support work into safe, parameterized automation.
2. Keeping credentials and environment-specific configuration outside source control.
3. Using queues to decouple producers and consumers and tolerate temporary downstream pressure.
4. Treating manufacturing telemetry as a data pipeline while maintaining a hard boundary around operational technology.
5. Using disposable labs to validate administration and automation ideas before applying them to authorised environments.

## Deliberate omissions

Older college exercises and obsolete personal projects are not treated as current professional evidence. The primary portfolio signal is infrastructure, cloud, identity, automation and integration work.
