## Featured work

### Infrastructure Automation
A practical automation collection covering Entra / Microsoft Graph reporting, Exchange auditing, Active Directory administration, Windows monitoring, Linux checks, Azure inventory, REST authentication and asynchronous messaging.

A safe IT/OT-style lab using synthetic machine telemetry, AMQP messaging, Python validation and anomaly detection. It demonstrates how plant-style data can flow into IT-side processing without connecting to real industrial equipment.

A Linux-based proof of concept demonstrating Ansible-driven deployment and configuration of Elasticsearch, Logstash, Kibana and supporting services.

Reproducible administrator scenarios covering resource inventory, virtual networking, VM operations, storage and monitoring, with security-conscious configuration boundaries.

## How I approach engineering

- Automate repetitive work instead of repeating it manually.
- Prefer clear, parameterized tools over hard-coded environments.
- Produce structured output that can be consumed by people or other systems.
- Keep credentials and environment-specific data outside source control.
- Document design decisions, limitations, validation and rollback.

## Portfolio safety

Public examples use synthetic or generic configuration. Employer, customer, tenant, credential, internal endpoint, proprietary binary and production telemetry are not part of the portfolio.
