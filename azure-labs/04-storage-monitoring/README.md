# Azure Storage and Monitoring Lab

## Objective

Demonstrate practical administration of Azure storage and platform monitoring.

## Scenario

Build a disposable lab that documents:

- storage account configuration choices
- blob/container organisation
- access model selection
- diagnostic settings
- metrics and alert thresholds
- lifecycle/retention considerations

## Evidence

Capture the architecture, commands, configuration decisions and sample outputs. Use synthetic names only.

The important part is the reasoning: choose the simplest safe configuration that meets the workload rather than enabling every available feature by default.
