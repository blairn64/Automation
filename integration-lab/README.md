# Integrated Enterprise Operations Lab

This lab ties the portfolio's major evidence areas into one synthetic operating model.

## Flow

5,000 users → identity events → service desk → network/application support → factory telemetry → RabbitMQ → processing → SQL/ERP boundary → Elastic/monitoring → incident response.

## Demonstrations

- Identity population and authentication analysis
- Multi-site support demand and escalation
- IIS-style application health checks
- SQL diagnostics and dependency tracing
- SAP-style transaction handling
- PLC/sensor telemetry and queueing
- Monitoring and detection
- Vulnerability prioritisation
- Root-cause and recovery workflows

All data and infrastructure in this lab are synthetic and clean-room. The purpose is to demonstrate engineering reasoning, not reproduce a private employer environment.
