# NoSQL / MongoDB Lab

## Purpose

A small document-store exercise showing how operational telemetry can be represented without a rigid relational schema.

## Demonstrates

- MongoDB document collections
- Python `pymongo` client usage
- Environment-based connection strings
- Projection and sorting
- Synthetic telemetry only

## Run

1. Start MongoDB in a disposable local/container lab.
2. Install `pymongo`.
3. Set `MONGO_URI` when the broker is not on localhost.
4. Run `mongo-demo.py`.

This is portfolio evidence for NoSQL/data handling. It is not presented as a copy of an employer system.
