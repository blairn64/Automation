# Azure VM Operations Lab

## Objective

Demonstrate routine administrator tasks around virtual machines without publishing a real environment.

## Scenario

Use a disposable VM to document:

- provisioning and tagging
- boot state checks
- OS disk/storage inspection
- restart/start/stop operations
- extension awareness
- basic monitoring hooks

## Evidence

Record the commands used, expected output and operational reasoning. Any examples must use placeholders for subscription IDs, resource groups, hostnames and IP addresses.

## Safety

Destructive operations should be tested with an explicitly disposable VM and clearly identified in the notes.
