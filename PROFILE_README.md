## How I approach engineering

- Automate repetitive work instead of repeating it manually.
- Prefer clear, parameterized tools over hard-coded environments.
- Make operational output structured and useful to other systems.
- Keep credentials and environment-specific data outside source control.
- Document design decisions, limitations and how to reproduce a result.

## Portfolio safety

Public examples use synthetic or generic configuration. Employer, customer, tenant, credential, internal endpoint and proprietary production data are not part of the portfolio.
