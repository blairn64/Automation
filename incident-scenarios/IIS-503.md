# IIS 503 — Application Pool Failure

**Symptoms:** Site returns HTTP 503 while the host is reachable.

**Evidence:** Check DNS/TCP, IIS bindings, site state, application-pool state and IIS logs.

**Isolation:** Determine whether the failure is site-wide, pool-specific or caused by a downstream dependency.

**Recovery:** Restore the approved application-pool/service state, then re-test the endpoint.

**Validation:** HTTP health check succeeds and application logs show normal startup.

**Prevention:** Monitor pool state and endpoint health; review recurring startup failures.
