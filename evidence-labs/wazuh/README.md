# Wazuh Detection Lab

This is a documentation-first Wazuh exercise for demonstrating security monitoring concepts safely.

## Scenario

Synthetic Linux and Windows telemetry is forwarded to a central security platform. Detection rules classify suspicious authentication, privilege and host-behaviour events.

## What to demonstrate

- Agent/server architecture
- Log collection and parsing
- Rule severity and grouping
- False-positive review
- Alert triage and escalation
- Separation of detection from remediation

## Interview angle

The useful skill is not memorising a vendor console. It is designing a repeatable path from telemetry to an actionable alert while controlling noise.

No employer logs, hostnames, credentials or proprietary rules are included.
