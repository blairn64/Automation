# Incident response scenarios

Short, reproducible troubleshooting exercises based on common enterprise support failures.

## Scenarios

- Factory telemetry outage
- IIS 503 / application pool failure
- SQL latency / blocking
- Identity failure spike after policy change
- Network segmentation fault
- Elastic ingestion gap
- Certificate expiry
- DNS dependency outage
- Queue backlog / consumer outage

## Investigation model

Each scenario follows:

**symptoms -> hypotheses -> evidence -> isolation -> remediation -> validation -> prevention**
